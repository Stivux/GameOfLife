# Игра "Жизнь" (Game of Life)

## 🎮 Управление

| Клавиша / Мышь | Действие | Условия |
| :--- | :--- | :--- |
| **Space** | **Старт/Пауза/Продолжение.** Запускает симуляцию или переключает паузу. | Всегда |
| **ЛКМ (Mouse 0)** | **Размещение/Удаление** клетки P1 (Игрок 1). | Только на **паузе** |
| **ПКМ (Mouse 1)** | **Размещение/Удаление** клетки P2 (Игрок 2). | Только на **паузе PvP режима** |
| **R** | **Рандомная генерация.** Заполняет видимую область случайными клетками. | Только на **паузе** |
| **↓ Down Arrow** | **Ускорение.** Уменьшает задержку между итерациями симуляции. | Только на **паузе** |
| **↑ Up Arrow** | **Замедление.** Увеличивает задержку между итерациями симуляции. | Только на **паузе** |
| **Esc** | Выход в главное меню. | Всегда |
